# Thư mục lưu ảnh kỷ niệm 📸✨

Bạn có thể lưu các tấm ảnh kỷ niệm của bạn thân vào thư mục này:
Ví dụ:
- `anh_nam1.jpg`
- `anh_totnghiep.jpg`
- `anh_nhom.jpg`

Sau đó, trong file `config.js`, bạn chỉ cần điền đường dẫn:
```javascript
img: "assets/images/anh_totnghiep.jpg",
frameStyle: "puppy", // hoặc 'polaroid', 'heart', 'magazine', 'rosegold', 'film'
```
